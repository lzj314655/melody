## 3. 联调期常见故障排查指南

| 现象 | 排查方向 |
|---|---|
| 首页空白 | `npm run dev` 是否启动;500 错误看后端日志 |
| 商品图不显示 | ① DevTools 看响应 Content-Type;② 是 `text/html` 则 vite proxy 没生效;③ 是 404 则 DB 路径与磁盘文件不匹配 |
| 登录后跳走 | 看 `localStorage` 的 token 是否设置;http.js 拦截器是否拿到 |
| 401 不断跳登录 | token 过期或后端 secret 变了;清 localStorage 重登 |
| 行为埋点没入库 | dev 模式被 Vite mock 截走;真实后端看 `BehaviorController` 日志 |
| 推荐接口空 | Redis 不可达 → 自动降级冷启动,看日志是否有 warn |
| 后台 403 | 当前账号 role 不够;查 `t_admin`/`t_role` |
