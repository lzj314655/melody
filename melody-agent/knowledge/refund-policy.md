# 退换货与退款政策

## 订单状态流转

订单状态按以下顺序流转：

```
待付款(PENDING_PAY) → 待发货(PENDING_SHIP) → 待收货(PENDING_RECEIVE) → 已完成(COMPLETED)
```

其他状态：售后中(AFTER_SALE)、已退款(REFUNDED)、已取消(CANCELED)。

## 取消订单

- **只有"待付款"的订单可以取消**（例如选择了支付宝支付但尚未付款的订单）。
- 取消后订单状态变为"已取消"，商品库存自动回滚。
- 钱包余额支付的订单下单时已扣款，不存在"待付款"状态，因此不能用"取消订单"，请走退款申请。

## 申请退款

- **"待收货"或"已完成"状态的订单可以申请退款**，需填写退款原因。
- 提交后订单进入"售后中"状态，等待管理员审核。
- 待付款（未支付）订单请直接取消，不要申请退款。

## 退款审核与到账

- 管理员在后台对"售后中"的订单进行审核：
  - **审核通过**：退款金额**原路退回用户钱包余额**（即时到账，可在钱包明细中查看"订单退款退回"流水），订单状态变为"已退款"。
  - 审核不通过：订单维持原状态，可联系平台客服沟通。
- 退款金额为订单实付金额（扣除优惠券优惠后的总价）。

## 退换货说明

- 本平台为零食类垂直电商演示系统（毕业设计沙箱环境），不产生真实物流与真实交易。
- 退货退款以钱包余额退回方式模拟，不涉及真实支付渠道原路退回。
