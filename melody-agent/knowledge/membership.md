# 会员等级与积分规则

## 成长值

- **1 元实付金额 = 1 点成长值**，下单支付成功后自动累计（支付宝待付款订单在实际付款确认后才累计）。
- 成长值只增不减，记录可在个人中心的成长值明细中查看。
- 退款不会扣回已获得的成长值。

## 会员等级划分（PRD §7.5）

按累计成长值自动升档，等级包括：

| 等级 | 成长值区间 |
|------|-----------|
| V0 普通用户 | 0 – 499 |
| V1 会员用户 | 500 – 1999 |
| V2 会员用户 | 2000 – 4999 |
| V3 会员用户 | 5000 及以上 |

- 等级在订单支付完成后**自动升级**，无需手动申请。
- 个人中心"会员等级"页展示当前等级、距离下一级所需成长值与等级权益说明。

## 积分规则

- **1 元实付金额 = 1 积分**，与成长值同步发放。
- 积分在订单支付完成时自动到账，可在个人中心积分明细中查看流水。
- 积分为演示用途，暂不支持积分兑换与抵现。

## 会员权益

- 高等级会员可享受平台定向发放的会员优惠券，以"领券中心"实际可领的券为准。
- 等级越高，代表在平台的活跃与消费贡献越高（用于展示与营销活动）。
